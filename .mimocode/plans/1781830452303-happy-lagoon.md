# Fix Migration: Label is_system column

## Problem
`prisma migrate dev` fails because the migration SQL references lowercase table names (`labels`, `teams`) but the schema uses PascalCase (`Label`, `Team`). SQLite error: `no such table: labels`.

## Fix
Update `prisma/migrations/20260619000000_label_is_system/migration.sql` to use PascalCase table names.

### Changed file
`prisma/migrations/20260619000000_label_is_system/migration.sql`

Replace all lowercase references:
- `labels` → `Label`
- `teams` → `Team`
- `team_id` → `team_id` (column names stay snake_case per the init migration)

### Verify
```bash
DATABASE_URL="file:./data/project-manager.db" npx prisma migrate dev
```
