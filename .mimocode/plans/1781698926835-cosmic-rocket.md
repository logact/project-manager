# Plan: Server-Side Image Storage

## Goal
When saving issue description, extract base64 images, upload them to the server, and store only the server URLs in the markdown.

## New Files

### 1. `app/api/images/upload/route.ts` — POST endpoint
- Accepts `FormData` with image file
- Saves to `data/images/<uuid>.<ext>`
- Returns `{ url: "/api/images/<uuid>.<ext>" }`

### 2. `app/api/images/[filename]/route.ts` — GET endpoint
- Reads file from `data/images/<filename>`
- Returns image with correct Content-Type

## Modifications

### `hooks/useIssues.ts`
- Add `extractAndUploadImages(markdown)` helper
- Before saving, extract `![alt](data:image/...;base64,...)` patterns
- Upload each image to server, get URL
- Replace base64 URLs with server URLs in markdown

### `lib/db.ts`
- Ensure `data/images/` directory exists on startup

### `.gitignore`
- Add `/data/images`

## Implementation Steps

1. Create `data/images` directory setup in `lib/db.ts`
2. Create `app/api/images/upload/route.ts`
3. Create `app/api/images/[filename]/route.ts`
4. Add image extraction/upload logic to `hooks/useIssues.ts`
5. Add `/data/images` to `.gitignore`

## Verification

1. Create issue with pasted image
2. Check `data/images/` for saved file
3. Verify description contains `/api/images/xxx.png` not base64
4. Reload page, image should display correctly
5. Test copy still works (paste as rich text)
